# Динамический прайс для azbuka46.ru

Цены на сайте подгружаются из `prices.csv`, который лежит в Я.Диске у менеджера компании. Менеджер правит файл в Excel — изменения попадают на сайт автоматически.

---

## Для менеджера: как поправить цену

### Один раз: настройка

1. Установить десктопное приложение **Я.Диск** ([disk.yandex.ru/download](https://disk.yandex.ru/download)) — для Windows или Mac.
2. Войти под аккаунтом, на котором лежит `prices.csv`.
3. После установки в системе появится синхронизируемая папка «Яндекс.Диск» (обычно в `Documents` или в домашней папке).
4. Найти в ней `prices.csv` — это и есть рабочий файл.

### Каждый раз: обновление цены

1. Открыть `prices.csv` в Excel (двойной клик).
2. Найти нужную строку. Колонки `product / row / tier` — **не трогать**, это адреса ячеек на сайте. Менять только `price`.
3. Поправить цифру (например, `1 600` → `1 700`).
4. **Cmd+S** (Mac) или **Ctrl+S** (Windows). Если Excel спрашивает формат — выбрать **«CSV UTF-8 (разделители — запятые)»**.
5. Подождать 10–15 секунд — Я.Диск автоматически синкнет файл в облако (зелёная галочка на иконке файла = синхронизировано).
6. На сайте новые цены подтянутся при следующей загрузке страницы (или сразу после Cmd+Shift+R).

### Как добавить новый товар / фасовку

Если на сайте появилась новая фасовка — скопируй существующую строку, поменяй цены и идентификаторы. Внимание: точные значения `product` / `row` / `tier` нужно согласовать с программистом (они должны совпадать с разметкой в HTML карточки).

### Что **нельзя** делать

- ❌ Удалять `prices.csv` и заливать заново — изменится публичная ссылка, и сайт перестанет видеть прайс.
- ❌ Менять заголовки колонок (`product`, `row`, `tier`, `price`).
- ❌ Менять идентификаторы (значения в `product` / `row` / `tier`) без согласования.
- ❌ Сохранять в формате `.xlsx` — должен оставаться `.csv`.

Если что-то сломалось — старые версии файла можно откатить через интерфейс Я.Диска (правой кнопкой → «История изменений»).

## Для программиста: устройство

### Как это работает

В HEAD сайта Tilda (Настройки сайта → Ещё → «Изменить HTML-код в HEAD») вставлены два `<script>`:

```html
<script>
  window.AZB_PRICES_CONFIG = {
    url: 'https://disk.yandex.ru/d/XXXXXXXXXXXXX',  // публичная ссылка на prices.csv
    cacheTTL: 300,    // секунды
    debug: false
  };
</script>
<script src="https://cdn.jsdelivr.net/gh/videojam46-beep/azbuka46-assets@main/loader/prices-loader.js"></script>
```

Дальше при загрузке страницы:

1. Загрузчик читает `window.AZB_PRICES_CONFIG`. Если конфига нет — молча выходит.
2. Проверяет `localStorage['azb-prices-cache-v1']`. Если кэш моложе `cacheTTL` — использует его.
3. Иначе для ссылки `disk.yandex.ru` / `yadi.sk` дёргает Я.Диск API:
   ```
   GET https://cloud-api.yandex.net/v1/disk/public/resources/download?public_key=<url>
   → { href: "https://downloader.disk.yandex.ru/…" }
   ```
   Для других хостов — использует URL как есть.
4. Скачивает CSV, кладёт в localStorage с timestamp.
5. Парсит CSV: пропускает пустые строки, строки начинающиеся с `#`, и повторные строки шапки (где первое поле = `product`).
6. Для каждой `[data-product]` карточки на странице, для каждой `tr[data-pack | data-thickness | data-epdm | data-fraction]` строки, для каждой `td[data-tier]` ячейки — ищет в прайсе ключ `product|row|tier` и подменяет `textContent`.
7. Если что-то сломалось (нет интернета, API упал, CSV битый) — `catch`, цены из HTML остаются. Сайт не падает.

### Адресация ячеек

Каждая цена адресуется тремя координатами:

| Атрибут на элементе | Что значит |
|---|---|
| `data-product` на `<article>` | Идентификатор товара (`pigment`, `sportex-klassik`, …) |
| `data-pack` / `data-thickness` / `data-epdm` / `data-fraction` на `<tr>` | Идентификатор строки таблицы (фасовка, толщина, % EPDM, фракция) |
| `data-tier` на `<td>` | Идентификатор колонки таблицы (тираж м², фасовка опт/розница, и т.п.) |

В CSV ключ строки — `product,row,tier,price` — соответствует именно этой тройке.

### Файлы

- `prices-loader.js` — сам загрузчик, ~150 строк vanilla JS, без зависимостей.
- `prices.csv` — эталонная версия прайса (для git-истории). Боевой прайс живёт в Я.Диске у клиента.
- Этот `README.md`.

### Подключение к сайту

1. Получить от клиента публичную ссылку на `prices.csv` в Я.Диске.
2. Tilda → Настройки сайта → Ещё → «Изменить HTML-код в HEAD».
3. Вставить два `<script>` (см. выше), подставив ссылку клиента в `url`.
4. Опубликовать сайт.

В карточках T123 ничего трогать не нужно — разметка уже готова, загрузчик сам найдёт ячейки.

### Обновление кода загрузчика

```sh
cd ~/Documents/Сайты/azbuka46-assets
# поправил prices-loader.js
git add loader/prices-loader.js
git commit -m "…"
git push
curl -s "https://purge.jsdelivr.net/gh/videojam46-beep/azbuka46-assets@main/loader/prices-loader.js"
```

Браузер может ещё какое-то время отдавать старую версию (HTTP-кэш). Hard refresh (Cmd+Shift+R) на тестовой странице покажет новую.

### Отладка

Включи `debug: true` в конфиге → в консоли появятся:
- `[azb-prices] загружаю прайс: <url>` или `[azb-prices] из кэша`
- `[azb-prices] применено ячеек: N`
- `[azb-prices] ошибка загрузки прайса: …`

Если применено 0 ячеек — проблема либо в `prices.csv` (ключи не совпадают с HTML), либо в разметке карточек (отсутствует какой-то data-атрибут). Проверь оба.

Чтобы сбросить кэш и загрузить заново — в консоли:
```js
localStorage.removeItem('azb-prices-cache-v1'); location.reload();
```
